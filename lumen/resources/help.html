Lumen

A small image viewer and light editor.

Getting started

Open an image with File › Open (Ctrl+O), drag a file or folder onto the window, or launch from a terminal:

lumen photo.jpg
lumen ~/Pictures

Opening a folder starts at the first image and lets you step through the rest. The window shows one image at a time; opening another replaces it.

Navigating

  • ← / → go to the previous / next image in the folder.
  • The mouse wheel also steps through images, unless it is set to zoom in Settings.
  • Click to advance (off by default) makes a left click go to the next image and a right click go back. It is ignored while a selection tool is armed, while a pasted layer is floating, or while the image is zoomed in far enough to pan.
  • Hidden files are skipped and names are sorted naturally (img2 comes before img10). Both can be changed in Settings.

Zoom and pan

  • Ctrl+wheel or a pinch gesture zooms around the pointer.
  • Ctrl++ / Ctrl+- zoom in and out, Ctrl+0 fits the window, Ctrl+1 is actual size.
  • Middle-drag pans. Left-drag pans too once the image is larger than the window.
  • Double-click toggles between fit and 100%.
  • F11 is full screen; Esc leaves it.

Selecting

Pick a tool from Select › Selection:

  • Square (S) drag a rectangle; hold Shift for a square, Alt to draw from the centre.
  • Circle (C) same, but an ellipse or circle.
  • Freehand (F) hold the left button and draw around the area.
  • Select › All (Ctrl+A) selects the whole canvas.
  • Esc clears the selection and puts the tool away.

The selection is drawn as animated "marching ants" and stays visible on any image. Clicking inside a finished selection with a tool active lifts those pixels so they can be dragged; Esc puts them back.

Copy, cut, paste and delete

  • Copy (Ctrl+C) copies the selection, or the whole image when nothing is selected.
  • Cut (Ctrl+X) copies and then clears the selection. The cleared area becomes transparent (or white, or a colour you choose in Settings).
  • Delete (Del) clears the selection without copying it.
  • Paste (Ctrl+V) drops an image onto the canvas as a floating layer. It arrives selected, with the ants around it.

Positioning a pasted layer

  • Drag inside the ants to move it; the arrow keys nudge by one pixel, Shift+arrow by ten.
  • Enter or a click outside the ants commits it to the canvas.
  • Esc throws it away.

Cropping

Make a selection and choose Select › Crop (Ctrl+Shift+X). The image is trimmed to the selection's bounding box; anything outside is discarded. With a freehand or circle selection the crop is still rectangular. Crop is undoable.

Saving

  • Save writes over the original file in its own format.
  • Before the first overwrite, Lumen keeps a copy named photo.jpg.bak next to the file (can be turned off in Settings).
  • Save As (Ctrl+Shift+S) writes a new file as PNG, JPEG, WebP, TIFF or BMP, with a quality setting for the lossy formats.
  • EXIF orientation is applied when an image loads, and the orientation tag is removed when it is saved, so the rotation is not applied twice.
  • An unsaved-change dot appears in the title and status bar. Opening another image, stepping to the next one, or closing asks whether to save, discard or cancel first.

Animated images

GIF and animated WebP files play automatically. View › Pause Animation or Space stops and restarts them. Animation frames cannot be edited in place; Save As writes the frame that is currently showing.

Slideshow

F5 starts a slideshow at the interval set in Settings. It stops when you make an edit, reach the end of the folder without looping, or press F5 again.

Settings

File › Settings (Ctrl+,). Every change applies immediately. Settings are stored in ~/.config/lumen/settings.json.

Formats and limits

Lumen reads PNG, JPEG, WebP, GIF, BMP, TIFF, ICO, TGA, PNM, XBM/XPM and SVG (SVG opens as a static image and cannot be edited). EXIF and ICC data are preserved where the format allows it. Editing an animated file is disabled so the animation is not destroyed.

Something went wrong

  • If a file will not open, check that it is not corrupt or a camera raw format; Lumen does not decode raw files.
  • If edits are not saved, look for an error dialog — permissions and read-only folders are the usual cause.
  • Settings can be reset from Settings › Restore defaults, and the folder holding them can be opened from the same window.
